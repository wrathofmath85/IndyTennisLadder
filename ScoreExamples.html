Score Submission Guide

Five common scenarios showing exactly how to fill out the score submission form. Find your situation below and follow the steps.

1

Straight Sets Win

Winner takes both sets cleanly. The most common outcome.

Scheduled Completed
How to fill it out
1

Match Type → Scheduled

This was your pre-assigned round matchup. Choose Challenge only if you arranged the match yourself.

2

Match Status → Completed

The match finished normally.

3

Winner → select the player who won

The scheduled opponent auto-fills below. You only pick the winner.

4

Enter S1 and S2 scores for each player

Use the dropdowns. In this example: winner won 6–3, 6–1. Leave S3 blank — the winner took two sets straight.

5

Leave Set tiebreak row empty

No set went to 7–6, so no tiebreak scores are needed.

Leave S3 completely blank when the match ends in two sets. Entering anything in S3 when the winner has already won two sets will cause a validation error.

2

Three-Set Win with a Set Tiebreak

Each player wins one set, then a full third set decides it. One set went to 7–6 so a tiebreak score is needed.

Scheduled Completed
How to fill it out
1

Match Type → Scheduled, Status → Completed

Standard completed match.

2

Leave the "match tiebreak" checkbox unchecked

This was a full third set, not a 10-point match tiebreak. The checkbox is only for super-tiebreaks.

3

Enter all three sets

Winner: 6 6 6 — Opponent: 3 7 2. Split 1–1 after two sets, winner takes set 3.

4

Set 2 was 7–6 → enter the tiebreak loser's score in S2 TB

The loser of the set tiebreak scored 3, so enter 3 in the S2 TB box. S1 TB and S3 TB stay blank (those sets weren't 7–6).

The tiebreak row records the loser's score only. If the tiebreak was 7–3, enter 3. If it was 7–5, enter 5. The TB boxes only unlock when the corresponding set is 7–6.

3

Match Tiebreak (10-Point Super Tiebreak)

Instead of a full third set, the match is decided by a 10-point tiebreak. Common in challenge matches.

Challenge Completed Match TB
How to fill it out
1

Match Type → Challenge

This match was arranged outside the scheduled pairings.

2

Check "Use 10-point match tiebreak instead of full third set"

This switches the S3 column to accept a freeform number (not limited to 0–7) and hides the set tiebreak row for S3.

3

Enter S1 and S2 scores as normal

Winner: 6 7 — Opponent: 7 5. S2 was 7–5 (not a tiebreak set).

4

Enter match tiebreak scores in the S3 boxes

Winner scored 10, loser scored 6 — enter those in the S3 column. Must win by 2, minimum 10 points.

The match tiebreak winner must have at least 10 points and win by 2. Valid examples: 10–6, 10–8, 12–10, 15–13. The "Set tiebreak" row is hidden for S3 when the match tiebreak checkbox is on.

4

Retired Mid-Match

A player retired due to injury or other reasons before the match concluded. Enter whatever score existed at the point of retirement.

Scheduled Retired
How to fill it out
1

Match Status → Retired

Do not use Completed. Selecting Retired signals to the scoring system that the match did not finish normally.

2

Winner → the player who was winning (or would have won)

Typically this is the player who did not retire.

3

Enter the score that existed at retirement

In this example the match was 4–0 in set 1 when the player retired. Enter 4 and 0 for S1, and 0/0 for S2 if the second set hadn't started. Leave S3 blank.

4

At least one score box must be filled

The form requires some score progress to be recorded. If the retirement happened immediately (no games played), contact the league admin.

The "Ret." suffix appears automatically in the preview line — you don't add it yourself. Just enter the scores as they stood and select Retired status.

5

Walkover

One player did not show up or had to withdraw before the match began. No scores are played.

Scheduled Walkover
How to fill it out
1

Match Status → Walkover

All score fields disable automatically. You do not need to enter any scores.

2

Winner → select the player who received the walkover

This is the player who showed up and was ready to play.

3

Leave all score boxes as-is (they're disabled)

The form will display zeros but these are ignored. Only the winner and walkover status are recorded.

4

Submit

The preview line will read "wins by walkover" confirming the status is set correctly.

Not sure if it's a Walkover or Retired? Walkover = match never started. Retired = match started but didn't finish. If any balls were hit, use Retired.
